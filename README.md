# Amazon Clone

A static front-end clone of the Amazon homepage, built for practice with HTML and CSS.

**Live demo:** coming soon (GitHub Pages)

## Features

- Navbar with logo, delivery location, search bar, account, orders, and cart icons
- Secondary panel with navigation links
- Hero banner with a promotional message
- Category cards for Fashion, Home Decor, Modern Spaces, Smart Home, Bedding and Bath, Kitchen and Dining, PC Computers, and Beauty
- Multi-column footer
- Amazon-style layout and color scheme
- Accessibility basics: semantic `<nav>` and `<main>` tags, plus labels on the search box and images

## Tech Stack

- HTML5
- CSS3 (Flexbox)
- Font Awesome icons

## Project Structure

- `index.html` is the page
- `style.css` holds all the styles
- The image files (`img1.jpg` to `img8.avif`, logos, and the hero image) sit in the same folder

## How to Run

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## What I Learned

- Structuring a multi-section e-commerce style layout
- Using Flexbox for layout and positioning
- Replicating a real-world UI closely with plain CSS
- Fixing CSS bugs, such as a broken `box-sizing` rule
- Using semantic HTML and ARIA labels

## Known Limitations

- Not responsive yet, so it is designed for desktop screens
- No JavaScript, so the cart, search, and sign-in do not work
