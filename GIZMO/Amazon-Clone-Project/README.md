# Amazon Clone

A front-end clone of the Amazon homepage built using HTML and CSS.

## Features

- Responsive navbar with search bar, account, orders, and cart icons
- Hero banner section with promotional deals
- Category cards section (Fashion, Home Decor, Modern Spaces, Smart Home)
- Amazon-style layout and color scheme

## Tech Stack

- HTML5
- CSS3

## What I learned

- Structuring a multi-section e-commerce style layout
- Working with flexbox/grid for responsive positioning
- Replicating a real-world UI closely using pure CSS

## Note

This is a static front-end clone built for practice — no backend or JavaScript functionality (cart, search, etc.) is implemented yet. This project will be updated with JS functionality once I complete learning JavaScript.
